# مشروع تطبيق الأندرويد الكامل: الدفتر الذكي للتجارة العامة (Android Native & Hybrid)

تم نقل التصميم الكامل والألوان والمنطق البرمجي حرفياً إلى نظام **أندرويد (Android)** باستخدام **Kotlin + Jetpack Compose + Material 3 + Room SQLite**، بالإضافة إلى تضمين محرك `HybridWebViewActivity` لتشغيل نسخة الويب المدمجة بدون إنترنت.

## المميزات المنقولة حرفياً لنظام الأندرويد:

1. **الألوان والهوية البصرية المطابقة 100%:**
   - الهيدر الكحلي الداكن (`#141E2E`) مع شريط التبويبات الثلاثي (`🔴 فاتورة بيع (A)`، `📋 كشف اليومية`، `🟢 التوريدات (B)`).
   - شبكة الأصناف الـ 16 المعتمدة حرفياً من كشف الحساب الورقي (خضراء، خصوصي، شبح بيضاء، شبح صفراء، عايدي، خصوصي صفراء، ممتاز، سوداء أصلي، سوداء أحمد قاسم، سوداء شيباني، الجابري، ح1، ح2، سلامي، B، H) بنفس درجات الألوان الخلفية والحدود والنصوص.

2. **فواتير البيع (🔴 التمييز البصري الأحمر - تبدأ برقم `A1001`):**
   - ترقيم تسلسلي محفوظ تلقائياً في `SharedPreferences` وقاعدة البيانات يبدأ من `A1001`، `A1002`...
   - خصم تلقائي دقيق من المخزون التراكمي للصنف عند حفظ الفاتورة.
   - فتح تطبيق واتساب الأصلي في أندرويد فوراً عبر `Intent(Intent.ACTION_VIEW)` لإرسال الفاتورة الجاهزة لرقم المدير.

3. **سندات التوريد ووارد البضاعة (🟢 التمييز البصري الأخضر - تبدأ برقم `B1001`):**
   - ترقيم تسلسلي يبدأ من `B1001`، `B1002`...
   - عرض **الكمية المدخلة (🟢)**، **الرصيد السابق بالمخزن**، و**الإجمالي التراكمي الموجود حالياً** في نافذة التوريد وفي بطاقة السند.
   - مشاركة فورية للسند المنفرد أو لتقرير الدفعات الشامل لكافة التصنيفات عبر واتساب.

4. **نظام الوحدات المزدوجة والتسمية الحرة:**
   - دعم كامل للوحدة الكبرى والوحدة الصغرى ومعامل التحويل مع صياغة عربية طبيعية (`5 كيلو ونص`، `نص كيلو`، `5 كيلو`).
   - أزرار اختصارات الكسور السريعة (`نص كيلو فقط`، `كيلو ونص`، `5 كيلو`، `5 كيلو ونص`).

5. **كشف الحساب اليومي الرقمي (20 سطراً):**
   - جدول ثنائي التمرير (`HorizontalScroll` + `VerticalScroll`) يعرض الـ 20 سطراً والـ 16 عموداً للأصناف مع صفوف `إجمالي البيع` و`إجمالي المتبقي بالمخزن`.

## خطوات التشغيل وبناء ملف APK في Android Studio:

1. قم بفك ضغط الملف `SmartTradeBook_Android_Project.zip`.
2. افتح برنامج **Android Studio** واختر **Open** ثم حدد مجلد المشروع.
3. انتظر اكتمال مزامنة `Gradle Sync`، ثم اضغط على **Run (▶)** أو اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)** لاستخراج ملف الـ `APK` وتثبيته مباشرة على الهاتف.
